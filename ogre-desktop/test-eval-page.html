🧪 Sample Test Cases

Test 1: Extract page title

await evalScript(`document.title`)

Expected: "Wave 0.2 Spike - Eval Test Page"

Test 2: Count elements

await evalScriptJSON(`({ divs: document.querySelectorAll('div').length, inputs: document.querySelectorAll('input').length })`)

Expected: Object with divs and inputs counts

Test 3: Extract all students

await evalScriptJSON(`[...document.querySelectorAll('.student-row')].map(row => ({ id: row.dataset.studentId, name: row.querySelector('.name')?.textContent, score: row.querySelector('.score')?.value }))`)

Expected: Array of 5 student objects with id, name, and score

Test 4: Calculate average score

await evalScriptJSON(`{ average: [...document.querySelectorAll('.score')].reduce((sum, el) => sum + parseFloat(el.value), 0) / document.querySelectorAll('.score').length }`)

Expected: Object with average property (should be ~88.2)

Test 5: Fill form field

await evalScript(`document.getElementById('test-input').value = 'New Value'; document.getElementById('test-input').value`)

Expected: "New Value"

Test 6: Error handling

await evalScript(`throw new Error("Test error")`)

Expected: Promise rejection with error message

Test 7: Async operation

await evalScriptJSON(`(async () => { await new Promise(r => setTimeout(r, 100)); return { delayed: 'success' }; })()`)

Expected: { delayed: 'success' } after 100ms
