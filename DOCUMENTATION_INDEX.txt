PROBLEM SUMMARY
================================================================================

ISSUE:
  GradingPanel drawer appears UNDER the webview despite z-index: 10000

ROOT CAUSE:
  Tauri webviews are native OS windows that always render above HTML
  CSS z-index has NO EFFECT on native windows

SOLUTION:
  Reduce webview width to leave space for drawer
  (Same approach as sidebar, which works perfectly)

IMPLEMENTATION:
  • Modify Browser.svelte (4 changes)
  • Modify GradingPanel.svelte (2 changes)
  • ~20 lines of code
  • 30 minutes total effort

RISK LEVEL:
  🟢 Very Low
  └─ Only affects webview positioning
  └─ No state changes
  └─ Easy to rollback
