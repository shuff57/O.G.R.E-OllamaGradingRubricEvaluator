GitHub Token Setup

×
Note: This token is for repository integration (accessing code, making commits, etc.). If you only want to use GitHub AI Models, configure that in the Config → GitHub tab instead (minimal scopes needed).

Follow these steps to create a GitHub Personal Access Token:

  1. Visit GitHub Settings:
    https://github.com/settings/tokens/new
  2. Fill in Token Details:
    • Note: O.G.R.E Repository Access
    • Expiration: Choose your preference (30 days, 90 days, or no expiration)
  3. Select Scopes (for repository features):
    Check these two boxes:
    repo - Full control of repositories
    user - Read user profile data
  4. Generate Token:
    Click the green "Generate token" button at the bottom of the page
  5. Copy Your Token:
    Important: Copy the token immediately! You won't be able to see it again.
    Token format: ghp_xxxxxxxxxxxx
  6. Paste in Extension:
    Return to this extension and paste your token in the "GitHub Integration" section below
Security: Your token is stored locally in Chrome's encrypted storage and never leaves your computer.
