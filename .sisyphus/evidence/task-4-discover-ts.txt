TYPES DEFINED
=============
- NavigationMode: "batch" | "sequential"
- FeedbackType: "textarea" | "tinymce-inline" | "tinymce-iframe" | "contenteditable" | "unknown"
- NavigationConfig: Navigation settings for sequential mode
- SelectorMap: CSS selectors for page elements
- FeedbackConfig: Feedback editor configuration
- SaveConfig: Save button configuration
- DiscoveryResult: Complete discovery result from AI
- SelectorValidation: Validation result for a single selector
- ValidationResults: Map of all selector validations
- DiscoveryRequest: Request parameters for discovery
- DiscoveryProgress: Progress event during discovery
- DiscoveryWorkflow: Complete workflow result
