# Evidence: Task 3 - Smart Truncation Produces Valid JSON

## Test: Large snapshot (1000 nodes) produces valid JSON

The DISCOVERY_USER_PROMPT_TEMPLATE function now uses smart truncation that:
1. Removes whole elements from the END of the array (not mid-string)
2. Re-stringifies the truncated array so it's always valid JSON
3. Adds a truncation note when truncation occurs

### Test Code:
```typescript
const largeDomSnapshot = Array(1000)
  .fill(null)
  .map((_, i) => ({
    depth: i % 8,
    tag: "div",
    attrs: { id: `elem-${i}` },
    text: `Element ${i}`,
    childCount: Math.floor(Math.random() * 10),
  }));

const prompt = DISCOVERY_USER_PROMPT_TEMPLATE(
  "https://example.com",
  largeDomSnapshot
);

// Extract JSON portion
const jsonMatch = prompt.match(/DOM SNAPSHOT[\s\S]*?:\n([\s\S]*?)\n\nLook at/);
if (jsonMatch) {
  const jsonStr = jsonMatch[1];
  console.log(`JSON length: ${jsonStr.length} chars`);
  
  // Verify it's valid JSON
  const parsed = JSON.parse(jsonStr);
  console.log(`Parsed successfully: ${parsed.length} nodes`);
  console.log(`Truncation note present: ${prompt.includes("truncated from")}`);
}
```
