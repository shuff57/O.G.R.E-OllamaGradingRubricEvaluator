## Manual E2E Test Procedure
When server is running, execute these commands:

### 1. Simulate desktop push
curl -s -X POST http://localhost:3456/internal/providers \
  -H "Content-Type: application/json" \
  -d '{"token":"desktop-gen-uuid","providers":[{"id":"openai","api_url":"https://api.openai.com/v1","model":"gpt-4o","is_active":true,"credentials":{"api_key":"sk-test"}}]}'

Expected: 200 OK with {"success":true,"count":1}

### 2. Extension handshake
curl -s -H "Origin: chrome-extension://test" http://localhost:3456/api/handshake

Expected: 200 OK with {"token":"desktop-gen-uuid"}

### 3. Extension fetch providers
curl -s -H "Authorization: Bearer desktop-gen-uuid" http://localhost:3456/api/providers

Expected: 200 OK with {"providers":[{"id":"openai",...}]}
