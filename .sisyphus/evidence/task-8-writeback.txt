## Implementation Details

### Model Dropdown Change Handler (line 348-369)
- Listens to 'change' event on modelName select
- Calls updateThinkingControls() for UI updates
- Sends fire-and-forget POST to /api/providers/active with:
  - provider_id: currentProviderId
  - model: selected model value
- Only sends if desktopConnected && handshakeToken

### Provider Switch Handler (line 1777-1820)
- Called when user clicks provider tab
- Updates currentProviderId and UI
- Sends fire-and-forget POST to /api/providers/active with:
  - provider_id: new provider ID
  - model: current model selection
- Only sends if desktopConnected && handshakeToken

### Error Handling
- Both POST calls use .catch() to log errors to console
- No UI blocking or error messages shown
- Fire-and-forget: UI continues regardless of response
- Next panel open will re-sync anyway (per spec)
