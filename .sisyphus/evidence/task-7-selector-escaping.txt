   - No arrow functions, no const/let, pure ES5 with `var` and character loops

   - Now: `'#' + cssEscape(el.id)` + uniqueness test
   - Before: manual replace for `:` and `.` only, no uniqueness check

3. Fixed Priority 2 (name attribute):
   - Now: `tag + '[name="' + quotedValue + '"]'` + uniqueness test
   - Before: `tag + '[name=' + el.name + ']'` (unquoted, no uniqueness check)

4. Fixed Priority 3 (semantic attributes):
   - Now: attribute values quoted with double quotes + uniqueness test
   - Before: attribute values unquoted, no uniqueness check

5. Fixed Priority 4 (class-based selector):
   - Now: up to 3 classes joined as `tag.cls1.cls2.cls3` + uniqueness test, falls through if non-unique
   - Before: only first class, no uniqueness check

6. All priorities now fall through to next if selector is non-unique (multiple matches) or throws
