9. **validateSelectors()**: Merges nav selectors for sequential mode, runs validation script via evalScript
10. **runDiscovery()**: Main exported workflow — capture → AI → parse → validate → return

### Workflow stages with progress callbacks:
- capturing (10%) — DOM snapshot + screenshot + URL in parallel
- analyzing (30%) — AI call with vision
- analyzing (60%) — parse response
- validating (80%) — test selectors on live page
- complete (100%) — return DiscoveryWorkflow
- error — on any failure
