# Fonts

The app embeds the five `Ogre*.ttf` files. `subset.py` builds them from the
full fonts in `original/`.

| Embedded file | Built from | License |
|---|---|---|
| `OgreSans-Regular.ttf`, `-Semibold`, `-Bold` | Source Sans 3 (Adobe), the files verSHion ships | SIL Open Font License 1.1 (`OFL-SourceSans3.txt`) |
| `OgreSerif-Regular.ttf` | Source Serif 4 (Adobe), the file verSHion ships | SIL Open Font License 1.1 (`OFL-SourceSerif4.txt`) |
| `OgreIcons.ttf` | Phosphor Icons, regular weight | MIT, Phosphor Icons (phosphoricons.com) |

The text faces are subsets, which the Open Font License treats as modified
versions; it reserves the name "Source" for unmodified fonts, so the subsets
are renamed. Their copyright and license records are unchanged.
